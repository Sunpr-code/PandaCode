# 🐼 PandaCode 中文编程器

用中文写 Python 代码！

## 特点
- 全中文关键字：如果/否则/对于/函数/类
- 三种模式：GUI / 命令行 / REPL
- 语法高亮 + 错误定位
- 打包成 exe，双击即用

## 截图
![GUI界面截图](/image.png "https://github.com/Sunpr-code/PandaCode/image.png")

## 示例
``` PDC
甲=6
如果 甲 ＞ 5：
    打印（"大了"）
```
### 输出
``` text
大了
```
---
## 快速开始
### Step1. 安装编译器
``` bash
git clone https://github.com/Sunpr-code/PandaCode.git
```
或直接下载发行版（跳过步骤2）

### Step2. 下载依赖（可选）
``` bash
pip install -r requirments.txt
```

### Step3. 开始编程！
``` bash
python PandaCode.py
# 或：
python -m PandaCode
```
#### 如果为Windows环境：
- 双击运行
- .\PandaCode.exe （PowerShell适用）
