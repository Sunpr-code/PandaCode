## 🎮 三种运行模式

PandaCode 提供三种运行模式，覆盖从「双击即用」到「命令行自动化」的全部场景。

---

### 🖥️ 模式一：图形界面（GUI）

**适合**：初学者、教学演示、日常写代码

**启动**：

```bash
python PandaCode.py
```

或双击打包好的 `PandaCode.exe`。

**功能**：

| 功能 | 说明 |
|------|------|
| 语法高亮 | 中文关键字按类型着色 |
| 行号显示 | 左侧实时显示行号 |
| 错误定位 | 出错时高亮对应行 |
| 一键翻译 | 按 `F6` 查看翻译后的 Python 代码 |
| 示例库 | 菜单栏内置 5 个示例程序 |
| 文件管理 | 新建 / 打开 / 保存 `.pdc` 文件 |

**快捷键**：

| 快捷键 | 功能 |
|--------|------|
| `F5` | 运行代码 |
| `F6` | 查看翻译 |
| `Ctrl + N` | 新建文件 |
| `Ctrl + O` | 打开文件 |
| `Ctrl + S` | 保存文件 |
| `Ctrl + Shift + S` | 另存为 |
| `Ctrl + L` | 清空输出 |

---

### 💻 模式二：命令行（CLI）

**适合**：开发者、脚本自动化、CI/CD 集成

**启动**：

```bash
# 运行 .pdc 文件
python PandaCode.py run 示例.pdc

# 直接执行一行代码
python PandaCode.py -e "打印（'你好'）"

# 查看翻译后的 Python 代码
python PandaCode.py translate 示例.pdc

# 查看版本
python PandaCode.py -v
```

**子命令一览**：

| 子命令 | 作用 | 示例 |
|--------|------|------|
| `run` | 运行 `.pdc` 文件 | `python PandaCode.py run x.pdc` |
| `translate` | 查看翻译结果 | `python PandaCode.py translate x.pdc` |
| `gui` | 启动图形界面 | `python PandaCode.py gui` |
| `repl` | 启动交互解释器 | `python PandaCode.py repl` |
| `-e` | 直接执行代码 | `python PandaCode.py -e "打印（1）"` |
| `-v` | 查看版本 | `python PandaCode.py -v` |

**适用场景**：

- 批量运行多个 `.pdc` 脚本
- 在 Shell 脚本里调用 PandaCode
- 配合计划任务定时执行
- 集成到 CI 流程里做自动化测试

---

### 🐼 模式三：交互式解释器（REPL）

**适合**：快速试验、学习语法、调试片段

**启动**：

```bash
python PandaCode.py repl
```

如果**在无图形环境下**（比如 Linux 服务器），直接运行 `python PandaCode.py` 会自动进入 REPL。

**核心特性**：

| 特性 | 说明 |
|------|------|
| 即输即执行 | 单行代码回车立即运行 |
| 多行块支持 | 以 `：` 结尾自动进入续行模式 |
| 表达式求值 | 输入 `甲 ＋ 乙` 直接输出结果 |
| 历史记录 | `↑` `↓` 翻看历史命令 |
| 变量查看 | 输入 `环境` 查看当前所有变量 |
| 内建命令 | 帮助 / 清空 / 环境 / 退出 |

**内建命令**：

| 命令 | 别名 | 作用 |
|------|------|------|
| `帮助` | `help` `?` | 显示帮助信息 |
| `清空` | `clear` | 清屏 |
| `环境` | `vars` | 查看当前变量 |
| `退出` | `exit` `quit` `q` | 退出 REPL |

**多行块示例**：

```text
🐼 >>> 函数 阶乘（n）：
   ...     如果 n ＜＝ 1：
   ...         返回 1
   ...     返回 n ＊ 阶乘（n － 1）
   ... 
🐼 >>> 阶乘（5）
120
```

## 🚀 快速选择

- **第一次用** → GUI，双击即开
- **想快速试验语法** → REPL，即输即执行
- **要批量运行脚本** → CLI，命令行一把梭
- **服务器 / 无图形环境** → 自动进 REPL
